# 物流综合轨迹展示

原生 HTML / CSS / JavaScript，无构建依赖。直接读取参考站点的公开查询接口，不包含模拟运单或服务器缓存。

## 本地运行

需要 Node.js 20 或更高版本。在此目录执行 `npm start`，打开 http://127.0.0.1:4173/?numbers=BG2608182036 。

运行 `npm test` 检查输入解析、接口响应归一化和 CSV 导出；`npm run check` 检查页面脚本语法。

## 功能

- 最多 20 个运单批量查询，自动去重，支持中文/英文逗号、分号和换行。
- 直接查询众乐国际真实数据；顺序请求，间隔 1 秒，单票 30 秒超时；支持取消、刷新及单票重试。
- 展示系统单号、客户单号、转单号、承运商、目的国家、邮编、件数和全部轨迹。
- 状态筛选、轨迹展开/收起、正反排序、轨迹关键词搜索。
- 复制单号、复制单票查询链接、导出全部成功结果及完整轨迹为 UTF-8 BOM CSV。
- 支持 `?numbers=单号1,单号2` 和原站形式 `#/tracking?numbers=单号`。
- 响应式桌面/手机布局；不保存查询记录到浏览器存储或数据库。

## 数据来源与限制

接口：`https://gzzlgj.nextsls.com/tracking/app?inajax=1&tracking_number=...`

接口地址及字段归一化位于 `dist/tracking.js`。截至本次验证，原站允许跨域匿名读取。页面在用户浏览器中直接请求原站，使用 `credentials: omit` 和 `referrerPolicy: no-referrer`，不转发登录凭据，也不代理其他目标站点。

原站配置要求 `sleepTime: 1000`；本实现按此设置顺序查询。该公开接口没有提供稳定性保证或正式 API 协议；如果原站调整字段、跨域设置或身份验证，需要更新接入方式。不会将接口失败伪装成无结果或演示数据。

时间完全按原站返回显示；原站未说明时区。运输中/待发筛选包含非异常、非签收状态；异常/未查到包含退件、取消、无结果和请求失败。顶部状态卡不代表整家公司业务统计，仅统计本次查询。

`dist/` 可部署到任意静态 HTTPS 主机。本站为独立查询展示工具，非众乐国际官方网站。单号保留在页面 URL 中便于分享；不应将包含私密单号的链接公开分享。
