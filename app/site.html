每一票货物，一目了然

  1. 输入系统单号、客户单号或转单号。支持换行、逗号或分号分隔，最多 20 个不同单号。

  3. 点击状态卡片筛选结果；展开运单可搜索、排序完整物流轨迹。

时间按数据源返回值显示；如包含时区偏移会保留，不推测未提供的时区。原站接口不可用时会显示失败，可稍后刷新或前往原站核验。

本站为独立查询工具。运单将提交给选定的物流数据服务，不同服务有各自的免费额度与访问条件；本站不建运单数据库。单号会出现在当前页面链接中，额外查询条件不会写入链接。
FREE CONNECTIONS

可扩展的免费数据源

正在检查接入状态…

  1. 众乐国际：公开接口，无需密钥。
  2. UPS：官方 Track API 对符合条件的 UPS 托运人免费；需要关联托运账号，在服务端配置 UPS_CLIENT_ID 与 UPS_CLIENT_SECRET。官方申请 ↗
  3. DHL：官方 Shipment Tracking Unified API 免费，默认每天 250 次、每 5 秒最多 1 次；取得密钥后在服务端配置 DHL_API_KEY。官方申请 ↗
  4. FedEx：Basic Integrated Visibility 免费，需要 FedEx 账号及项目；服务端配置 FEDEX_CLIENT_ID 和 FEDEX_CLIENT_SECRET。官方申请 ↗
  5. USPS：官方 Tracking API 对符合条件的托运人免费，需 USPS Business 账号及追踪授权；服务端配置 USPS_CLIENT_ID 与 USPS_CLIENT_SECRET。官方申请 ↗
  6. Karrio 自托管：开源（LGPL-3.0），可扩展其他承运商。需自行部署并连接各家物流商账号；服务端配置 KARRIO_BASE_URL 与 KARRIO_API_KEY。开源项目 ↗

这些接口没有统一的“免费查遍所有物流商”权限。UPS 官方 Track API 仅对符合条件的托运人开放；未获得授权时可使用官网核验。密钥只放在服务端环境变量，不提交 GitHub。
