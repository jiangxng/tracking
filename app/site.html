QUICK GUIDE

每一票货物，一目了然

  1. 输入系统单号、客户单号或转单号。支持换行、逗号或分号分隔，最多 20 个不同单号。
  2. 点击查询，逐票向选定数据源查询。Ship24 首次查询最长可能需约 1 分钟；已建立追踪的运单会返回服务端最新结果。
  3. 点击状态卡片筛选结果；展开运单可搜索、排序完整物流轨迹。
  4. “导出”下载本次全部成功结果的 CSV；“复制链接”可再次打开指定运单。

时间按数据源返回值显示；如包含时区偏移会保留，不推测未提供的时区。原站接口不可用时会显示失败，可稍后刷新或前往原站核验。

本站为独立查询工具。运单将提交给选定的物流数据服务，Ship24 会创建并持续维护追踪记录，可能消耗账号额度；本站不建运单数据库。单号会出现在当前页面链接中，额外查询条件不会写入链接。

  1. 在 Ship24 注册账号，选择 Tracking API & Webhook · Per-shipment 套餐。免费试用配额和价格以服务商页面为准。
  2. 在 Ship24 后台的 API Keys 页面创建密钥。
  3. 部署时将密钥设为服务端环境变量 SHIP24_API_KEY。请勿填写到聊天、前端文件或 GitHub。
  4. 刷新本页即可加载承运商目录并开始查询。

相同参数重复查询不会重复创建追踪；修改承运商、目的地或发货日期可能创建新的追踪并消耗额度。个别渠道需要邮编、账号或其他补充信息，不能保证所有包裹都能查到。
